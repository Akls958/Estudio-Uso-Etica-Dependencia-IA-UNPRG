# Estudio: Uso Académico, Prácticas Éticas y Dependencia a la IA Generativa

**Curso:** Fundamentos de Estadística
**Institución:** Universidad Nacional Pedro Ruiz Gallo (UNPRG)  
**Grupo:** 6  

## 📄 Descripción del Proyecto
Este repositorio contiene el material suplementario, la base de datos y los análisis estadísticos realizados para el proyecto final de curso. El objetivo fue determinar la relación entre el uso de herramientas como ChatGPT y la dependencia académica en estudiantes universitarios.

## 📂 Contenido del Repositorio

* **`Base_Datos_Final.sav`**: Archivo de datos procesado en IBM SPSS 27.
* **`Data_Original.xlsx`**: Matriz de datos original exportada desde Google Forms.
* **`Output_Resultados.docx`**: Reporte completo de tablas y gráficos generados.
* **`Instrumento.pdf`**: Cuestionario utilizado para la recolección de datos.

## 🛠 Herramientas Utilizadas
* **Recolección:** Google Forms.
* **Procesamiento:** Microsoft Excel.
* **Análisis Estadístico:** IBM SPSS Statistics 27 (Pruebas de Normalidad, Tau-b de Kendall).
